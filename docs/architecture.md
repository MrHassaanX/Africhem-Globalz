# Current application architecture

Current-state review: 3 November 2026. This note describes the repository as it exists now; dated phase reports below are historical snapshots.

## Stack and entry points

- Next.js 16.3.7 App Router, React 19, TypeScript, Tailwind CSS 4/PostCSS.
- `app/layout.tsx` supplies metadata, local Inter and Inter Tight fonts, the shared Header/Footer, the skip link, providers and first-visit intro.
- `app/page.tsx` renders `components/home/HomePage.tsx`. Page content is server-rendered unless a component needs browser interaction.
- `app/template.tsx` provides the route transition; `app/not-found.tsx` handles missing routes.
- `next.config.ts` defines legacy redirects, image formats and security headers.
- `app/robots.ts` and `app/sitemap.ts` follow `SITE_INDEXABLE`. Review mode is the default.

## Shared design and interaction system

`styles/tokens.css` defines the shared colors, spacing and type scale. The visual language combines warm cream/mineral surfaces, deep navy, industrial blue and teal; the official logo retains its supplied colors. Local variable fonts avoid remote font requests. Light is the default theme; the header toggle persists a preference in local storage and synchronizes it across tabs. Theme initialization runs before paint where possible.

The Header uses desktop navigation and a native dialog menu at narrower widths. The shared shell includes visible keyboard focus, a skip link and responsive behavior. Keep shared visual changes scoped to their intended component or tokens.

`components/Providers.tsx` owns the shared Lenis/GSAP scroll lifecycle. Page-specific GSAP interactions clean up on unmount and preserve readable static content. Reduced-motion preferences and static fallbacks are supported. `components/global-reach/GlobalReachGlobe.tsx` loads its Three.js renderer lazily; the page has a static poster/fallback and keyboard/touch interaction. Globe arcs are illustrative network cues, not shipping routes.

## Content model and trust boundaries

- `lib/content/company.ts` is the reusable source for client-provided company wording, pillars, values, contact and partner countries.
- `lib/chemical-catalogue.ts` contains five chemical families and two named chemical products: White Spirit and Thinner. Unknown grade, stock, origin, packaging, pricing and technical documents remain absent.
- `lib/businesses.ts` distinguishes documented secondary businesses from entries awaiting details.
- `lib/verified-content.ts` holds optional legal/founder identity fields and public proof points. Empty or unapproved values are not rendered.
- `lib/quote.ts` validates form fields and determines whether transport is configured.

Seven international partner countries are identified as partner locations; they do not establish Africhem offices, warehouses, subsidiaries or specific shipping lanes. Stock photography is illustrative. Do not invent missing commercial, technical, legal or operational facts.

## Quotation endpoint and environment

`app/contact/page.tsx` renders `components/quote/QuoteForm.tsx`; `app/api/quote/route.ts` validates and bounds the JSON request, checks origin, uses a honeypot and a best-effort in-memory cooldown, and calls Resend only when all server-side settings are present. The UI remains disabled unless `QUOTE_FORM_ENABLED=true`, `RESEND_API_KEY`, `ENQUIRY_FROM_EMAIL` and `ENQUIRY_TO_EMAIL` are set. A provider-accepted message is not proof of inbox receipt. No database, buyer auto-reply or durable distributed rate limiter is present.

Copy `.env.example` to `.env.local` for local overrides. Keep credentials server-only and never commit `.env.local`. Do not enable live delivery until the destination mailbox and sender are approved and a real receipt has been confirmed.

## Indexing and publication

`SITE_INDEXABLE` defaults to false. While false, robots metadata and an `X-Robots-Tag: noindex, nofollow` response header keep review builds out of search results, and the sitemap is empty. `SITE_URL` supplies the canonical base URL and currently defaults to `https://www.africhem-globalz.com`; verify it before launch. Legal pages remain drafts pending founder/legal review.

## Local development

Use Node.js 22 LTS or newer. From the repository root:

```powershell
npm ci
npm run dev
```

Then open `http://localhost:3000`. Other scripts are listed in the repository README. Next.js guidance for the installed version is in `node_modules/next/dist/docs/` and must be consulted before changing Next.js code or conventions.
