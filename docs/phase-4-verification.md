## Actual performance measurements

Measured from a local optimized production build:

- Initial home HTML script set: 13 scripts; 736,928 bytes raw and 232,812 bytes after local gzip compression.
- Deferred GSAP/ScrollTrigger: 115,088 bytes raw; 44,587 bytes gzip.
- Local variable DM Sans font: 36,932 bytes.
- Generated 1200x630 social PNG: 373,151 bytes.
- Generated 64px icon: 5,449 bytes; 180px Apple icon: 35,536 bytes.
- Original server-side logo source: 1,116,085 bytes.
- No hero raster image, video, canvas or 3D library transfer.

These are byte counts/local gzip results, not measured production network totals or a Lighthouse score. Lighthouse is not installed; the supplied browser read scope does not expose performance observers. LCP, CLS and INP were not measured; no score is estimated. Device/field measurements and a production Lighthouse run remain launch-review work.

Server content, local font and lazy scene initialization reduce the initial load. Framework and Motion are the largest initial JS costs; GSAP is deferred. Social artwork is not on the homepage critical path. Motion mainly uses transform/opacity; route traces use a small SVG stroke animation.
